**Mod** means **Cmd** on macOS and **Ctrl** on Windows.

## Default shortcuts

| Action | Shortcut | Rebindable |
|---|---|---|
| Run query or statement | Mod+Enter | No (editor) |
| Command palette | Mod+K | Yes |
| New query tab | Mod+T | Yes |
| Close tab | Mod+W | Yes |
| Next tab | Mod+Shift+] | Yes |
| Previous tab | Mod+Shift+[ | Yes |
| Open IntelliShell | Mod+Shift+I | Yes |
| Open aggregation editor | Mod+Shift+A | Yes |
| Open SQL Query | Mod+Shift+Q | Yes |
| Refresh current collection | Mod+R or F5 | Yes |
| Settings | Mod+, | Yes |
| Lock MotionQL | Mod+L (works inside editors too) | Yes |
| New connection | Mod+N | No |
| Quick connect 1–9 | Mod+1…9 or Mod+Alt+1…9 | No |
| Reload window | Mod+Alt+R | No |
| Quit | Mod+Q | No |

## Rebind a shortcut

Open **Settings → Keyboard** (**Mod+,**), find the action and record a new key combination. Standard editing shortcuts (copy, paste, cut, select all, undo, redo) can't be rebound.

## Inside code editors

When the cursor is in a code editor (IntelliShell, the aggregation editor, SQL Query), the editor keeps its own shortcuts for keys it uses, such as Mod+K, Mod+Shift+[ and ], Mod+Shift+I, Mod+F and Mod+/. **Lock** (Mod+L) always works.

## Quick connect

Assign a saved connection to a number in the Connection Manager, then press **Mod+1** to **Mod+9** to connect to it from anywhere.
